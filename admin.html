チャンネル管理

要約一覧へ戻る

フォロー中の YouTube チャンネルを追加・削除します。

最初の設定（1回だけ）

このページから GitHub のファイルを書き換えるために、専用のアクセストークンを1つ作ります。 作ったトークンはこの端末のブラウザだけに保存され、他には送られません。

  1. GitHub のトークン発行ページを開く （GitHub にログインしていなければログインします）
  2. Token name：好きな名前（例：youtube-yoyaku 管理）
  3. Expiration：好きな期間（切れたら同じ手順で作り直します）
  4. Repository access：Only select repositories を選び、 git-san-934/youtube-yoyaku を選ぶ
  5. Permissions → Repository permissions → Contents を Read and write にする （ほかの権限は不要）
  6. 下の Generate token で作成し、表示された github_pat_… をコピー
  7. それを下の欄に貼って「保存」

例：https://www.youtube.com/@pivot00 ／ @pivot00

ページの読み込みでエラーが発生しました。時間をおいて再度お試しください。

追加・削除は GitHub 上の data/channels.json に保存されます。 新しく追加したチャンネルは、正式なチャンネルIDへの変換（1〜2分）のあと、 次回の要約更新（6時間おき）から対象になります。
