# ユビキタス言語定義 — ユーチューブ要約

本アプリの関係者（開発者・利用者）が同じ意味で言葉を使うための用語集。
コード上の識別子・JSONキー・画面文言は本書を正とする。

## ドメイン用語

| 日本語 | 英語 / コード上の名前 | 定義 |
|---|---|---|
| チャンネル | channel | 監視対象の YouTube 投稿者。`@名` と `channel_id` で識別する |
| ハンドル（@名） | handle | `@senxotimes` のような `@` で始まるチャンネルの短縮名。人が指定する入口 |
| チャンネルID | channel_id | `UC` で始まる YouTube 内部ID。RSS取得のキー。@名から一度だけ解決する |
| フォローリスト | channels（`data/channels.json`） | 監視対象チャンネルの一覧。利用者が編集する |
| 動画 | video | 1本の YouTube 動画。`video_id` で識別する |
| 動画ID | video_id | YouTube の11文字前後の動画識別子。`watch?v=` の後ろの値 |
| 新着動画 | new video | フォロー中チャンネルが公開した動画のうち、未要約かつ公開が `LOOKBACK_DAYS` 以内のもの |
| 要約 | summary | 動画の内容を Gemini が日本語でまとめた短い文章（結論先行・箇条書き3〜6点・最大400字程度） |
| 要約カード | card | 一覧画面で動画1本を表す表示単位（サムネイル・タイトル・チャンネル名・公開日時・要約） |
| 要約一覧 | summaries（`data/summaries.json`） | 要約済み動画を新しい順に並べたデータ。フロントが読む唯一のデータ源 |
| 新着チェック | update run | `update.py` の1回の実行。RSS確認 → 新着抽出 → 要約 → 保存までの一連 |
| 要約準備中 | failed | 要約に失敗し、次回実行で再試行される状態（`status: "failed"`） |
| 取りこぼし | miss | 実行間隔中にRSSの保持件数を超えて更新され、検知できなかった動画。実用上は許容 |

## ステータス値（`items[].status`）

| 値 | 意味 | 画面表示 |
|---|---|---|
| `ok` | 要約に成功した | 要約本文を表示 |
| `failed` | 要約に失敗した（次回再試行） | 「要約準備中」と表示 |

## 設定値（`scripts/update.py` 冒頭の定数）

| 名前 | 既定値 | 意味 |
|---|---|---|
| `MODEL` | `gemini-2.5-flash` | 要約に使う Gemini モデル |
| `MAX_PER_RUN` | `6` | 1回の実行で要約する最大件数（残りは次回へ） |
| `LOOKBACK_DAYS` | `5` | 「新着」とみなす公開からの日数 |
| `MAX_NEW_PER_CHANNEL` | `4` | 1チャンネルあたり1回の実行で拾う新着の最大本数 |
| `KEEP_ITEMS` | `200` | `summaries.json` に残す最大件数（古いものを切り捨て） |
| `MAX_RETRY` | `3` | 同じ動画の要約をリトライする上限回数 |

## UI/UX 用語

| 画面上の呼び方 | 対応するコード | 説明 |
|---|---|---|
| ユーチューブ要約 | （アプリ名） | 本アプリの表示名。リポジトリ名は `youtube-yoyaku` |
| チャンネル絞り込み | filter / `renderFilter()` | 一覧を特定チャンネルだけに絞るプルダウン |
| 最終更新 | `updated_at` | `summaries.json` が最後に生成された時刻 |
| 注意書き | disclaimer | 「要約はAIが自動生成したもので、正確性は保証しません」の固定文言 |

## 外部サービス用語

| 用語 | 説明 |
|---|---|
| YouTube 公開RSS | チャンネルごとの最新動画を配信するフィード（`videos.xml?channel_id=...`）。ログイン・APIキー不要 |
| Gemini API | Google の生成AI API。本アプリでは動画URLを入力して日本語要約を得るために使う |
| Google AI Studio のキー | Gemini API を無料枠で使うためのAPIキー。GitHub Actions Secrets に `GEMINI_API_KEY` として登録 |
| GitHub Pages | 静的サイトの無料ホスティング。`main` ブランチのルートを配信 |
| GitHub Actions | リポジトリ上でスクリプトを定期実行する無料の仕組み。`update.py` を回す |
| Secrets | GitHub リポジトリに暗号化して保管する秘密情報。ソースには現れない |
