# プロダクト要求定義書 — ユーチューブ要約

## ビジョン・目的
毎日チェックしている決まった投稿者（YouTubeチャンネル）の新着動画を、
見る前に「何を話しているか」を短い日本語の要約で把握できるようにする。
動画を再生しなくても内容の当たりがつき、見る／見ないを数秒で判断できることを目指す。

## ターゲットユーザーと課題
- 投資・経済・時事系のYouTubeチャンネルを毎日複数フォローしている個人（本人）。
- 課題:
  - フォロー数が多く、新着があるか一つずつ確認するのが手間。
  - 1本30〜60分の動画も多く、全部見る時間はない。中身を知ってから選びたい。
  - 通知欄や登録チャンネル一覧では「今日どれを見るべきか」が分かりにくい。

## 主要な機能
1. 見たい投稿者（チャンネル）のリストを登録しておく。
2. 1日数回、自動で各チャンネルの新着動画をチェックする（YouTubeの公開情報のみ利用。ログイン不要）。
3. 新着動画が見つかったら、AI（Google Gemini）に内容を日本語で要約させる。
4. 要約を1つのWebページに新しい順で一覧表示する。
   - サムネイル画像、動画タイトル、チャンネル名、公開日時、要約本文、YouTubeへのリンク。
5. チャンネルの追加・削除ができる（設定ファイルの編集で対応）。
6. ポータルページ（わたしのあぷり）からリンクで開ける。

## 成功の定義
- スマホ／PCのブラウザでページを開くと、フォロー中チャンネルの最近の新着動画が
  要約つきで新しい順に並んでいる。
- 新しい動画が公開されてから、おおむね数時間以内に要約がページに反映される。
- 要約を読めば、その動画の主題と要点（3〜6行程度）が分かる。
- ポータルページから遷移して使える。

## ビジネス要件
- 運用コストは無料の範囲で完結させる（GitHub の無料枠 ＋ Gemini API の無料枠）。
- 無料枠を超えそうな場合は、要約の頻度・対象・精度を下げて調整する。
- 個人情報・アカウント・ログインを扱わない。YouTubeアカウントとも連携しない。

## 非機能要件
- 静的ホスティング（GitHub Pages）で表示できること。サーバーは持たない。
- 自動チェック・要約処理は GitHub Actions（無料の自動実行）で動かすこと。
- Gemini API キーはソースコードに書かず、GitHub の秘密情報（Secrets）として保管すること。
- 一部のチャンネルの取得や要約に失敗しても、ページ全体は壊れないこと
  （そのチャンネル分だけスキップし、次回再試行する）。
- スマホ幅で横スクロールが発生しないこと。ダークモード対応。
- 要約はAIが生成したものであり内容の正確性を保証しない、という注意書きをページに表示すること。
- 動画・チャンネルの著作物本文をそのまま転載しない（あくまで要約）。
