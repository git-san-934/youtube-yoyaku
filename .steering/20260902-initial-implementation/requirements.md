# requirements.md — 初回実装（ユーチューブ要約）

## この作業でやること
フォロー中の YouTube チャンネルの新着動画を自動で見つけ、Google Gemini で日本語要約を作り、
1つのWebページに新しい順で一覧表示する。誰でもブラウザで開けるよう GitHub Pages に公開し、
ポータル（わたしのあぷり）からリンクでたどれるようにする。

## ユーザーストーリー
- フォロー中チャンネルの新着を、1つずつ確認しなくてもまとめて把握したい。
- 動画を再生する前に、要点（結論・箇条書き）を読んで見る／見ないを決めたい。
- スマホでもPCでも見やすく開きたい。
- 特定のチャンネルの新着だけに絞って眺めたい。
- チャンネルの追加・削除を自分でできるようにしたい。

## 受け入れ条件
1. `data/channels.json` に初期20チャンネルが `handle` / `channel_id` / `name` 付きで登録されている。
2. `scripts/resolve_channels.py` を実行すると、`handle` だけの行に `channel_id` と `name` が補完される。
   解決できなかった `handle` はエラーとして一覧表示され、処理は継続する。
3. `scripts/update.py` を実行すると:
   - 各チャンネルの公開RSSを取得し、未要約かつ公開5日以内の動画を新着として集める
     （1チャンネルあたり1回最大4本）。
   - 1回の実行で最大4件まで、公開が古い順に Gemini で要約する。
   - 要約は日本語・結論先行・箇条書き3〜6点・最大400字程度。
   - 成功した動画は `status: "ok"`、失敗した動画は `status: "failed"` で `data/summaries.json` に記録される。
   - `summaries.json` は新しい順・最大200件に保たれる。既存の要約は消えない。
   - 1つのチャンネルや1本の動画で失敗しても、他の処理は最後まで進む。
   - `GEMINI_API_KEY` が未設定なら、要約はスキップし新着の一覧化だけ行う（`status: "failed"`）。
4. `index.html` をブラウザで開くと:
   - ヘッダーにアプリ名・最終更新時刻・「要約はAIが自動生成。正確性は保証しません」の注意書きが出る。
   - チャンネル名のプルダウン（「すべて」＋登録チャンネル）で一覧を絞り込める。
   - 動画カードが新しい順に並ぶ。各カードにサムネイル・タイトル（YouTubeへのリンク）・
     チャンネル名・公開日時（相対／短縮表記）・要約本文が表示される。
   - `status: "failed"` のカードは要約の代わりに「要約準備中」と表示される。
   - 要約が1件もないときは「まだ新しい動画の要約はありません」と表示される。
5. スマホ幅で横スクロールが発生しない。ライト／ダークモードの両方で表示が崩れない。
6. `.github/workflows/update.yml` により、6時間おきと手動実行で `update.py` が動き、
   変更があれば `data/summaries.json` が自動でコミット・push される。
7. `README.md` に「GitHub Pages の公開設定」「Gemini キーの取得と Secrets 登録」
   「チャンネルの追加手順」「ローカルでの確認方法」が書かれている。
8. ポータルの `index.html`（別リポジトリ `portal`）に「ユーチューブ要約」へのカード／リンクが追加されている。
9. 公開後、`https://git-san-934.github.io/youtube-yoyaku/` で一覧が表示される。

## 制約事項
- サーバーは持たない。GitHub Pages（静的）＋ GitHub Actions（定期実行）のみ。無料の範囲で完結させる。
- 要約は Gemini API の無料枠（Google AI Studio のキー）を前提とする。
  超過時は 1実行あたり件数・対象日数・モデルを絞って対応する（コード定数で調整可能）。
- ブラウザから外部API（YouTube / Gemini）を直接呼ばない。フロントが読むのは `data/summaries.json` のみ。
- `GEMINI_API_KEY` はソース・フロントに置かず、GitHub Actions Secrets のみに保管する。
- 個人情報・ログイン・YouTube アカウント連携は扱わない。
- 動画の字幕・説明文の全文転載はしない（あくまで要約）。
- メンバー限定・地域制限などで Gemini が解釈できない動画は `failed` のままとし、`MAX_RETRY` 超過で諦める。
