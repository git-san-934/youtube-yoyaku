# requirements.md — チャンネルを Web から追加・削除する（管理ページ）

## この作業でやること
フォロー中チャンネルの一覧（`data/channels.json`）を、ファイルを直接いじらずに
スマホのブラウザから追加・削除できる専用ページ `admin.html` を作る。
書き込みは GitHub のアクセストークン（この端末にだけ保存）を使って GitHub API 経由で行う。
チャンネルの正式ID（UC...）への変換は GitHub Actions 側で自動的に行う。

## ユーザーストーリー
- 見たいチャンネルが増えたら、その場で「チャンネルのURL」か「@名」を貼って追加したい。
- 見なくなったチャンネルは一覧から削除したい。
- パソコンを開かず iPhone だけで完結させたい。
- 難しい設定は最初の1回だけにしたい。

## 受け入れ条件

### トークンの設定（初回のみ）
1. `admin.html` を開くと、トークン未設定なら「設定手順」と入力欄が表示される。
2. 手順には、GitHub のトークン発行ページへのリンクと、選ぶ項目（対象リポジトリ＝
   `youtube-yoyaku` のみ／権限＝Contents の読み書き）が日本語で書かれている。
3. トークンを貼って保存すると、この端末のブラウザ（`localStorage`）にだけ保存される。
   トークンはリポジトリにコミットされない。
4. トークンが無効・期限切れのときは「トークンが使えません。再設定してください」と表示し、
   入力欄に戻れる。「トークンを削除」ボタンでいつでも消せる。

### 一覧の表示・削除
5. トークン設定後、`data/channels.json` の現在の一覧が名前つきで表示される。
6. 各行に「削除」ボタンがある。押すと「削除しますか？ 削除／やめる」の確認が出る。
7. 正式IDへの変換がまだのチャンネルは「変換待ち」と表示される。
8. 「削除」確定で GitHub に保存し、「保存しました。1〜2分で反映されます」と表示する。

### 追加
9. 入力欄に次のいずれかを入れて「追加」できる:
   - `@name`
   - `https://www.youtube.com/@name`（余分なパス・クエリが付いていてもよい）
   - `youtube.com/@name` / `name`（@なし）
   - `https://www.youtube.com/channel/UC...`（この場合は正式IDを直接登録）
10. すでに登録済みの @名／IDなら「すでに登録されています」と出して追加しない。
11. 追加すると `channels.json` に `{ "handle": "@name" }`（または channel_id 付き）を足して
    GitHub に保存し、「追加しました。変換のあと数分で要約対象になります」と表示する。

### 反映（GitHub Actions）
12. `data/channels.json` が変更されると、`resolve_channels.py` を実行する workflow が動き、
    `handle` だけの行に `channel_id` と `name` を補完して自動コミットする。
13. 変換できない @名（打ち間違いなど）は「変換待ち」のまま残る。ユーザーが確認して削除できる。
14. 変換後、次回の「要約データ更新」（6時間おき／手動）でそのチャンネルの新着が要約対象になる。

### その他
15. `index.html` のフッターに、目立たない形で「チャンネルを管理」リンクを置く。
16. `admin.html` は検索エンジンに載せない（`noindex`）。トークンが無ければ何も操作できない。
17. `localStorage` が使えない環境でも、ページがクラッシュせずメッセージを出す。
18. スマホ幅で横スクロールが出ない。ライト／ダークの両方で崩れない。

## 制約事項
- サーバーは持たない。書き込みは GitHub API（Contents API）＋ 端末保存のトークンのみ。
- トークンは「このリポジトリだけ」「Contents の読み書きだけ」の細粒度トークンを前提とする。
- `admin.html` は公開URLだが、トークンが無いと一覧取得も保存もできない。
- ブラウザから YouTube を直接叩かない（CORS 不可）。ID変換は Actions に任せる。
- `scripts/update.py` は変更しない（channel_id 未設定の行は既にスキップ対応済み）。
- `data/summaries.json` は変更しない。

## スコープ外（将来検討）
- 複数端末でのトークン共有・同期。
- 追加時のブラウザ内での @名の実在チェック（Actions の変換結果で判断する）。
- チャンネル削除時に、そのチャンネルの過去の要約も消す処理。
- 並べ替え・グループ分け・一時停止などの管理機能。
